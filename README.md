# Java Lab 5 - Linked List Practice

A student linked-list implementation with custom nodes. This lab explores insertion, deletion and simple computations over integer values.

## Exercises included
- Insert at the front, back or after a target
- Delete from the front, back or a selected position
- Display the list
- Count occurrences and even values
- Find maximum and related calculations

## Run
The Java files use package `ihablab4`. Create that package in Eclipse and add `Node.java`, `linkedlist.java`, and `linkmain.java`. Run `linkmain.java`.

## Note
This linked-list exercise includes node constructors, traversal, insertion, deletion, averaging, maximum-value search and sorted-order checks. Positions in `deleteatposition` are 1-based.
